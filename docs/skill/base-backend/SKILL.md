# Desenvolvimento do Base Backend

Antes de executar uma tarefa, leia integralmente [`../../rule/PROJECT_RULES.md`](../../rule/PROJECT_RULES.md) e cumpra suas regras.

Consulte o handoff do serviço em `../../handoff/` para obter o contexto atual. Quando o handoff principal indicar documentos complementares, leia somente os que forem relevantes para a tarefa.

Para qualquer trabalho relacionado ao Gonthera CLI, consulte a documentação oficial indicada nas regras antes de analisar ou alterar a implementação.

Depois de compreender os requisitos, limite a alteração ao escopo confirmado, preserve código manual fora de `_gen` e valide o resultado com os comandos apropriados ao risco da mudança.

Atualize o handoff quando a tarefa produzir contexto de continuidade, decisões arquiteturais, pendências ou resultados de validação que sejam relevantes para trabalhos futuros.
